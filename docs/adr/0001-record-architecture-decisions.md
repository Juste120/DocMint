# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-25

## Context

Agbale is a public open source project meant to be understandable by any developer who
discovers it (constitution, Principle I). Choices made today (engines, licences, security model)
will be questioned by future contributors.

## Decision

Record every significant technical decision as a short Markdown ADR in `docs/adr/`, numbered,
with context, decision, consequences and alternatives considered. Accepted ADRs are not edited;
a new ADR supersedes an old one.

## Consequences

Decisions stay discoverable next to the code. Pull requests that make a significant choice must
add an ADR (pull request template checklist).
