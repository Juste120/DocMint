# @juste120/docmint-angular

Angular helpers to view, download and preview documents generated by
[DocMint](https://github.com/Juste120/DocMint) endpoints (`@Report`).

```bash
npm install @juste120/docmint-angular
```

```ts
import { Component, inject } from '@angular/core';
import { DocMintClient, DocMintError } from '@juste120/docmint-angular';

@Component({
  selector: 'app-invoice',
  template: `
    <button (click)="docs.view('/api/invoices/1/pdf').subscribe()">Voir</button>
    <button (click)="docs.download('/api/invoices/1/pdf').subscribe()">Télécharger</button>
  `,
})
export class InvoiceComponent {
  readonly docs = inject(DocMintClient);   // needs provideHttpClient()
}
```

- `view(url)` opens the PDF in a new tab, `download(url)` saves it with the server's file name,
  `preview(url)` returns an object URL for `<img [src]>` (release it with `release(url)`).
- Errors are `DocMintError` with `status`, `code` (e.g. `DOCMINT_TEMPLATE_NOT_FOUND`), `title`
  and `detail`, read from the RFC 9457 body even though it arrives as a `Blob`.
- With CORS, expose `Content-Disposition` on the API, otherwise the file name is hidden.
